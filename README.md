## 📖 它是什么

**河岸凝视 (Riparian Gaze)** 是一个为 SillyTavern 设计的**超长文本因果时间线与世界状态管理器**。
它不仅能让你像使用 Git 版本控制一样管理你的跑团/RP故事线（锚定、回溯、分支），更在后台搭载了一个**全自动的世界状态机**。它通过大语言模型静默提取每一轮对话的因果 JSON 档案，结合向量检索（Vector）与大模型重排（LLM Rerank），彻底解决超长叙事中 AI 遗忘、时空错乱、NPC 凭空消失、物品状态矛盾等痛点。

## 🧩 核心功能模块全景解析

打开插件面板后，你将看到以下高度集成的模块：

### 🌳 1. 因果树 (Causal Tree Canvas)
你的个人故事线 Git 控制台。
- **可视化分支画布**：通过银色发光贝塞尔曲线连接的树状图，全览你的主线与所有探索过的分支。支持拖拽平移、双指缩放。
- **因果锚点快照**：一键保存当前剧情节点（支持命名、撰写描述），同时快照当前的 MVU 变量（`stat_data`）和消息可见性。
- **无缝时空跳跃**：点击任意历史节点即可“穿越”回溯。系统会自动隐藏后续多余消息、恢复对应的世界变量，让你能随时换个选项重新推演。

### 🗺️ 2. 地理树 (Geo Spatial Tracking)
像翻看真实的地图册一样管理世界。
- **多层级拓扑生成**：自动从对话中解析 `国家/省份/城市/街道/建筑` 的树状结构，不再是一团乱麻的地名词云。
- **严格同名区分**：通过父级节点严格隔离同名地点（如甲国首都与乙国首都），防止地名幻觉。
- **动态描述更新**：自动记录“主角初遇之地”、“曾发生战斗的废墟”等地点累积特征。
- **优雅的实体合并**：如果 AI 建错了地点，在编辑面板中使用**内嵌下拉栏**一键合并入目标地点，彻底清理冗余分支。

### 👥 3. 人物志 (NPC Archive)
记录所有过客的生平与状态流转。
- **智能消歧义**：后台引擎自动根据上下文，将“老师”、“那个人”、“哥哥”等代称归一化到具体的建档角色身上。
- **状态流转追踪**：不只记录“他是谁”，更详细记录他在时间线中经历的生理受伤、心理情绪、关系变动。
- **动态年龄锚点**：首次提及年龄即建立时间锚点，后续随剧情内时间流逝由系统自动推算。
- **时间线合并**：将错认的角色（如“陈明”与“陈老师”）通过下拉栏合并，两者的经历与时间线会自动完美衔接。

### 📦 4. 物品流转 (Item Lifecycle)
防止神兵利器凭空消失或突然复原。
- **生命周期追踪**：精细追踪每一件重要物品的**获得、失去、使用、损毁、移交**全过程。
- **多称呼绑定**：将“那个黑盒子”、“有浮雕的容器”自动归一化为标准名“封印之盒”。
- **持有者与状态快照**：实时明确物品“在谁手上”、“当前是什么状态”（如：已破损、已充能）。

### 📝 5. 总结池 (Summary Pool)
宏观剧情的备忘录。
- **手动/自动定速挡**：支持手动生成，或设定每隔 N 轮自动执行全局总结。
- **全量无损提取**：强制要求 AI 穷尽式记录“因果事件链”与“悬置因果线”（伏笔），杜绝过度精简导致的剧情断代。
- **防误触编辑与检索**：全屏查看过往总结，支持全局关键词搜索，点击原文直接在原位展开编辑框，拒绝烦人的次级弹窗。

### 🧠 6. 观测引擎 (Digest & Retrieval API)
静默在后台为你守望世界的一致性。
- **因果观测仪 (Digest JSON)**：在后台阅读高信息量回合，将其转化为包含 `narrative`、`location`、`characters` 等数组的结构化 JSON 进行本地归档。
- **向量召回 (Vector Search)**：基于语义相似度，提取历史长河中的相关事实碎片。
- **因果一致性终审官 (LLM Rerank) [独创]**：由 LLM 对向量召回的记忆进行二次终审打分。强制过滤时间/空间冲突片段（例如：旧记录显示门是锁的，当前语境门已被炸毁，则直接将旧记录排异并标记失效），拒绝前言不搭后语的“缝合怪”记忆。

### 🌐 7. 诸世界管理 (World Controller)
数据完全脱离聊天文件的限制。
- **独立持久化存储**：世界数据保存在系统级 `settings.json` 中，你的聊天记录就算意外清空，心血也不会丢。
- **跨档解绑与关联**：随时可以将当前聊天切换绑定到另一个“世界”，或者为丢失的记录重新“挂载”世界。
- **导入/导出**：一键将完整的世界（含地理、人物、因果树）导出为 JSON 文件分享给朋友，或者跨设备迁移。

### ⚙️ 8. 全权引擎设置 (Engine Settings)
最高自由度的调度中心。
- **多链路解耦配置**：总结、观测(Digest)、向量化(Vector)、重排(Rerank) 四大步骤支持分别配置不同的 API 接口与模型（例如用便宜的模型做摘要，用 Claude 3.5 做复杂的观测提炼）。
- **一键拉取模型**：直连配置下拉栏一键拉取可用模型列表。
- **Prompt 完全透明**：所有的硬核提示词模板（包括严苛的地理映射规则、消歧义规则）全部对外暴露，进阶玩家可自由微调。

## 🚀 安装指南

1. 下载或 `git clone` 本仓库到 SillyTavern 的 `data/default-user/extensions/` 目录下。
2. 重启 SillyTavern 或刷新页面。
3. 在魔法棒菜单（Extensions Menu）中找到「🌊 河岸凝视」。
4. 或在扩展设置中启用并点击「打开河岸凝视面板」。

## 📂 数据架构与存储说明

本插件不污染原有的聊天记录文件，所有数据采用极致清晰的树状结构持久化。

```text
extension_settings.RiparianGaze
├── enabled          ← 插件总开关
├── api              ← 全局引擎设置（API 密钥、Prompt、TopK 阈值，跨世界共享）
└── worlds           ← 所有被观测的世界容器
    └── [worldId]
        ├── name, chatId, createdAt
        ├── nodes[]        ← 因果树节点（含对话指针与 MVU 快照）
        ├── geoTree{}      ← 多层级空间地理树档案
        ├── npcArchive{}   ← 角色档案与状态流转时间线
        ├── itemArchive{}  ← 物品生命周期库
        └── currentNodeId  ← 观测者当前停留的节点
```

## 🛠️ 技术细节与兼容性

- **零外部依赖**：纯 Vanilla JavaScript (IIFE 封装)，不使用任何 `import` 或第三方库，保证极限兼容。
- **极致的 UI 适配**：移动端全屏响应式、触摸拖拽、双指缩放。使用 `position:fixed` 覆盖层，无缝融入 SillyTavern UI。
- **DOM 隔离设计**：所有动态注入的元素均采用特定前缀的 Scoped CSS 样式，并强制 `writing-mode: horizontal-tb` 防止被外部主题破坏布局。
- **异步兼容**：未使用 `async/await`，全 `.then()` 链式调用，兼容老旧设备与 WebView。

## ❓ 常见问题 (FAQ)

**Q: 聊天记录不小心清空/丢失了，我的因果树和地理档案还在吗？**
> 在的。所有世界数据独立存储在 `extension_settings` 中。你只需要重新导入一份哪怕是空白的聊天文件，然后到插件的「诸世界」标签页，选中你的旧世界点击「关联当前聊天」即可满血复活。

**Q: 我把同一个角色的两个称呼建成了两条独立档案，能修吗？**
> 非常简单。打开「人物志」面板，点击其中一个档案的「编辑」，下方有一个「合并到...」的下拉栏。选择另一个名字并确认，它的所有历史轨迹会自动无缝并入目标，原有错误档案会被安全销毁。地点和物品同理。

**Q: 总结 API 一直提示连不上？**
> 请确认在「引擎设置」里填写了 API 基础地址（如 `https://api.openai.com` 或第三方的中转地址），插件会自动补全 `/v1/chat/completions`。一定要点击右侧的「拉取模型」或「测试」按钮确认连通性。
