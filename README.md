# 🌊 河岸凝视 The Riparian Gaze

**SillyTavern 因果时间线管理插件**

在命运之河的岸边，观测因果的分裂与汇聚。

---

## 它是什么

河岸凝视是一个为 SillyTavern 设计的**因果时间线管理器**。它让你在 RP/跑团/沉浸式叙事中，随时锚定剧情节点、回溯分支、恢复世界状态，像版本控制一样管理你的故事线。

每个聊天窗口对应一个「被观测世界」，所有数据独立存储在服务器端的 `extension_settings` 中，不怕聊天记录丢失或重置。

---

## 核心功能

### ⚓ 因果锚定
- 一键快照当前剧情状态（消息索引 + MVU 变量）
- 命名、描述每个时间节点
- 支持快速回复按钮 `/tlg_anchor` 或面板内点击

### 🌿 因果树
- 银色发光贝塞尔曲线连接的树状图
- 可视化所有分支节点及其因果关系
- 支持拖拽平移、双指缩放
- 点击节点查看详情并跳转

### ↩ 时间跳转
- 跳转至任意历史节点
- 自动恢复 MVU 变量（`stat_data`）至存档点状态
- 智能消息可见性：只显示因果路径上的消息 + 最近 N 条上下文

### 📁 档案库
- 所有节点的列表视图
- 支持编辑描述、删除、跳转

### 📝 总结池
- 手动/自动模式（每 N 轮提醒锚定）
- 接入外部 API 自动生成结构化总结（对最新对话内容）
- 全屏历史列表，支持关键词搜索
- 原地展开编辑，防误触

### 🌐 诸世界
- 每个聊天窗口绑定一个独立的「世界」
- 自定义命名、手动关联、切换世界
- 导入/导出世界为 JSON 文件
- 聊天记录丢失后可重新关联，数据不受影响

### ⚙️ 引擎设置
- 配置总结 API 地址、密钥、模型
- 一键拉取模型列表
- 向量 API 接口（可选，用于语义检索历史）
- 所有 API 配置跨世界共享，全局持久化

## 安装

1. 下载或 `git clone` 本仓库到 SillyTavern 的 `data/default-user/extensions/` 目录下
2. 重启 SillyTavern 或刷新页面
3. 在魔法棒菜单（extensionsMenu）中找到「🌊 河岸凝视」
4. 或在扩展设置中启用并点击「打开河岸凝视面板」

---

## 使用方式

| 操作 | 方式 |
|------|------|
| 打开面板 | 魔法棒菜单 → 河岸凝视 |
| 创建锚定 | 面板内按钮 / 快速回复 `/tlg_anchor` |
| 跳转节点 | 因果树点击节点 → 确认跳转 |
| 生成总结 | 总结池 → 立即生成总结 |
| 查看历史总结 | 总结池 → 查看全部历史总结 |
| 切换世界 | 诸世界 → 选择目标世界 |
| 关联聊天 | 诸世界 → 对未关联世界点击「关联当前聊天」 |
| 导入世界 | 诸世界 → 导入世界（选择 JSON 文件） |
| 导出世界 | 诸世界 → 对应世界卡片上点击「导出」 |
| 开关插件 | 扩展设置 → 河岸凝视 → 启用开关 |

## 数据存储

```
extension_settings.RiparianGaze
├── enabled          ← 开关
├── api              ← 全局 API 设置（跨世界共享）
│   ├── apiUrl, apiKey, model, modelList
│   ├── vectorUrl, vectorKey, vectorModel
│   ├── summaryPrompt, vectorPrompt
│   └── autoMode, autoInterval, lastNMessages
└── worlds           ← 所有世界数据
    └── [worldId]
        ├── name, chatId, createdAt, updatedAt
        ├── nodes[]        ← 因果树节点
        ├── summaries[]    ← 总结记录
        └── currentNodeId  ← 当前所在节点
```

- 数据存储在 `extension_settings`（服务器端 `settings.json` 文件），独立于聊天文件
- 每个聊天的 `chat_metadata` 仅存一个 `tlg_worldId` 指针
- 聊天文件丢失/重新导入后，可通过「诸世界」标签手动重新关联

---

## 与 MVU 变量框架的联动

本插件可读写 MVU 插件的 `stat_data` 变量。锚定时自动快照当前世界状态，跳转时自动恢复。适配使用 Zod schema 管理变量的工作流。

## 常见问题

**Q: 聊天记录消失了，数据还在吗？**

在。所有世界数据存储在 `extension_settings` 中，不依赖具体聊天文件。重新导入聊天后，到「诸世界」标签手动关联即可恢复。

**Q: 切换聊天后再打开面板，显示的是新世界？**

每个聊天对应独立的世界。如果是新聊天（未关联任何世界），首次创建锚定时会自动生成。如果想用旧世界，到「诸世界」标签手动关联。

**Q: 总结 API 连不上？**

确认在「引擎设置」里填写了 API 基础地址（如 `https://api.openai.com`），插件会自动补全 `/v1/chat/completions` 路径。点击「测试」按钮确认连通性。

**Q: 导出的 JSON 文件可以分享给别人吗？**

可以。导出的 JSON 包含完整的因果树和总结记录，其他人导入后可以直接使用。

## 技术细节

- 无外部依赖，不使用 `import`，纯 IIFE 封装
- 通过 `window.SillyTavern.getContext()` 获取 ST API
- 使用 MutationObserver 确保按钮稳定注入
- 移动端全屏适配、触摸拖拽、双指缩放
- 面板 `position:fixed` + `z-index:2147483647` 全屏覆盖
- 所有按钮强制 `writing-mode:horizontal-tb` 防止主题干扰
- 不使用 `async/await`，全 `.then()` 链，兼容老旧 WebView
